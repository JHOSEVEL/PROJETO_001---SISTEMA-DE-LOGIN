Documentação para validação de uma aplicação de **Sistema de Login**. Este repositório cobre o fluxo completo do processo de QA: **Requisito → Cenário → Caso de Teste → Execução → Evidência → Bug Report**.

---

## 📌 Sobre o Projeto

O objetivo principal deste projeto é aplicar os conceitos essenciais do **QA Manual** na validação de um fluxo de autenticação de usuários.

### Escopo da Aplicação
A aplicação testa (AUT) em um sistema de login composto por:
- Campo de **E-mail**
- Campo de **Senha**
- Botão **Login**
- Link **"Esqueci minha senha"**
- Tratamento e exibição de **Mensagens de erro**
- Fluxo de **Cadastro de usuário**

---

## 🎯 Objetivos de Aprendizado

- Estruturação de um **Plano de Teste** claro.
- Mapeamento e escrita de **Cenários de Teste** (definindo do *o que* testar).
- Elaboração de **Casos de Teste** detalhados (definindo do *como* testar).
- Criação e gestão de **Massa de Dados**.
- Coleta de **Evidências de Teste**.
- Reporte e documentação de falhas (**Bug Reports**).
- Construção de **Matriz de Rastreabilidade**.
