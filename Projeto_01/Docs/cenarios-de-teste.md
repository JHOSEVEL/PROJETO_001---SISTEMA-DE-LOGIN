## 🧪 Cenários e Casos de Teste (CTN-01 — Login)

**Mapeamento de Cenários**

    CTN-LOGIN-01: Validar autenticação com credenciais válidas.

    CTN-LOGIN-02: Validar bloqueio de acesso com senha incorreta.

    CTN-LOGIN-03: Validar tentativa de login com e-mail não cadastrado.

    CTN-LOGIN-04: Validar comportamento do sistema com campos obrigatórios vazios.

    CTN-LOGIN-05: Validar comportamento do sistema com formato de e-mail inválido.

    CTN-LOGIN-06: Validar regra de negócio após múltiplas tentativas incorretas.
